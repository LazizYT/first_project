# ⚔️ Cyber-Oni Samurai — 3D Gaming Experience

Интерактивный игровой веб-лендинг нового поколения в киберпанк/аниме стилистике с Three.js, трехмерным трекингом взгляда и спиральной 3D-галереей арсенала.

🌐 **Репозиторий:** [https://github.com/LazizYT/first_project](https://github.com/LazizYT/first_project)

---

## 🚀 Ключевые особенности

### 1. 👺 Интерактивный 3D Hero (Они-Самурай)
- **Three.js & GLTF**: 3D-модель боевого робота-самурая с настраиваемыми материалами и свечением.
- **Интерактивный трекинг мыши**: самурай плавно следит головой и корпусом за курсором мыши в реальном времени.
- **Тактический HUD**: живая телеметрия поворота (Yaw / Pitch), статус сканирования и счетчик FPS.
- **Палитра неоновых скинов**: 4 цветовые темы (Crimson Malice, Void Cyan, Toxic Acid, Imperial Gold) с динамической перекраской материалов и интерфейса.
- **Web Audio API**: процедурные звуковые эффекты сервоприводов, клинков и кибер-интерфейса без внешних аудиофайлов.

### 2. 🔥 3D Spiral Helix Gallery (Пылающий Клинок Мурамаса)
- **Центральный 3D-меч**: вертикально вонзенный огненный клинок с вихрем алых искр и плазменным свечением.
- **Спиральная 3D-орбита**: 7 стеклянных карточек арсенала (3 зацикленных видео + 4 концепт-арта), двигающихся по спирали от верхнего левого угла через центр к правому нижнему при скролле.
- **Оптимизация 60+ FPS**: адаптивный рендеринг через `IntersectionObserver` и разгрузка GPU.

### 3. ⚡ Интерактивная Кибер-Кузница & Арсенал Оперативников
- Интерактивный терминал калибровки плазменного лезвия с частицами на Canvas 2D.
- Сетка оперативников с переключением боевых классов, характеристиками и звуковым откликом.
- Тактическая панель боевых операций «Synapse Raid» и футер в стилистике игрового лаунчера.

---

## 🛠 Стек технологий
- **Vite** — сверхбыстрый бандлер и dev-сервер
- **Three.js** — 3D-сцены, освещение, частицы и загрузка GLTF/GLB
- **Vanilla JavaScript (ES Modules)** — производительная модульная логика
- **HTML5 & Modern CSS3** — 3D CSS transforms, градиенты, backdrop-эффекты и адаптивный дизайн
- **Web Audio API** — синтез звука в реальном времени

## 💻 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/LazizYT/first_project.git

# Перейти в папку
cd first_project

# Установить зависимости
npm install

# Запустить локальный сервер
npm run dev
```

После запуска проект откроется по адресу `http://localhost:3000/`.
