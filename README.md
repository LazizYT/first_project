## 📸 Галерея и скриншоты проекта

### 1. Главный экран: 3D Они-Самурай с непрерывным трекингом взгляда и мистической аурой
> *Интерактивный 3D-самурай в темных матовых доспехах непрерывно следит за курсором мыши, окутанный пылающей демонической аурой душ и чакра-частиц.*

<div align="center">
  <img src="./docs/images/preview-hero.png" alt="Cyber-Oni Samurai Hero 3D Section" width="950" />
</div>

- **Непрерывный трекинг курсора**: голова и корпус самурая всегда следуют за курсором мыши без засыпания.
- **Мистическая они-аура**: многослойное объемное свечение за спиной воина и вихрь из 280+ восходящих духовных искр и лепестков пламени.
- **Чистый кинематографичный интерфейс**: академический фокус на 3D-персонаже и ключевых метриках обучения (40+ часов, 7 проектов, 1-on-1 менторство).
- **Динамический переключатель палитр**: мгновенная смена 4 неоновых стилей (*Crimson Malice*, *Void Cyan*, *Toxic Acid*, *Imperial Gold*) с синхронной перекраской источников света, ауры и материалов.
- **Процедурный аудио-синтезатор**: звуки сервоприводов, плазмы и кликов, генерируемые на лету через `Web Audio API`.

---

### 2. Секция «Arsenal of Skills»: 3D-спираль модулей курса вокруг клинка и древа Active Theory
> *7 практических модулей обучения в спиральной 3D-орбите вокруг огненного меча и биомеханических лент Active Theory. Меч и древо непрерывно следуют за движениями курсора мыши.*

<div align="center">
  <img src="./docs/images/preview-spiral-sword.png" alt="3D Spiral Helix Gallery Around Flaming Sword" width="950" />
</div>

- **Чистый обзор клинка без лишних колец**: убраны мелкие кольца позвонков, лезвие и гарда Мурамаса полностью открыты и сияют сквозь вихрь спор.
- **Непрерывное следование за мышью (Continuous Mouse Follow)**: клинок и ленты древа динамически поворачиваются и наклоняются в 3D вслед за курсором мыши с инерционным демпфированием.
- **Биомеханическое древо Active Theory**: двойная спираль сияющих лент (double-helix ribbons), ветвящаяся крона, корневая система и вихрь из 460+ хроматических спор.
- **7 учебных модулей в орбите**: Blender Hard-Surface, PBR-текстурирование, риггинг персонажей, Three.js ядро, GLSL шейдеры, интерактивная физика и дипломный проект для Awwwards.
- **Плавная физика скролла**: алгоритм с интерполяцией движения (`lerp damping`), амфитеатральным наклоном карточек и динамическим масштабированием.

## 💻 Установка и быстрый старт

### Требования:
- [Node.js](https://nodejs.org/) (версии 18 или новее)
- Git

### 1. Клонирование репозитория
```bash
git clone https://github.com/LazizYT/first_project.git
cd first_project
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере **`http://localhost:3000/`**.

### 4. Сборка для продакшена
```bash
npm run build
```
Собранные оптимизированные файлы появятся в директории `dist/`.
